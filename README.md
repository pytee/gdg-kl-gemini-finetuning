# Optimizing Gemini 3.5 Flash via Supervised Fine-Tuning on Gemini Enterprise Agent Platform

Hands-on workshop codelab for GDG Kuala Lumpur, conducted by Christine Tee, Principal Machine Learning Engineer, Turing Enterprises.

**Open the codelab:** https://pytee.github.io/gdg-kl-gemini-finetuning/

You'll fine-tune Gemini 3.5 Flash for article summarization on the WikiLingua dataset, measure a baseline with ROUGE, launch a managed LoRA tuning job, and compare the tuned model against the base model.
